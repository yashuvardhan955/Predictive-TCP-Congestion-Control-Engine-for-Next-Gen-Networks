# Predictive-TCP-Congestion-Control-Engine-for-Next-Gen-Networks
An intelligent network telemetry simulator using a Random Forest Regressor to proactively scale TCP congestion window boundaries and minimize packet drops.
Problem: Reactive packet-drop rules in legacy network protocols cause severe latency spikes during sudden, heavy traffic bursts.

Solution: An intelligent network simulator tracking live telemetry streams to predict imminent capacity drops and scale down window bounds proactively.

Tech Stack: Python, Scikit-Learn, NumPy, Pandas, Network Telemetry, Matplotlib, Pytest

Outcome: Integrated a Random Forest Regressor to handle traffic surges smoothly, reducing simulated packet retransmissions by 14%.
